Правила сервера

Общие положения +

1. Запрещено использование стороннего ПО, дающего преимущество.

2. Уважительное отношение к другим игрокам обязательно.

3. Запрещено читерство (читы, скрипты, макросы).

4. Запрещён обход бана.

5. Запрещена реклама других серверов.

6. Запрещён обман администрации.

7. Запрещён слив личных данных игроков.

8. Запрещено использование багов (багоюз).

9. Запрещён фейк администрации.

10. Запрещено оскорбление администрации.

Терминология +

RP (RolePlay) — игра по ролям, отыгрывание персонажа.

DM (Deathmatch) — убийство без РП-причины.

DB (DriveBy) — убийство из машины.

SK (Spawn Kill) — убийство на спавне.

TK (Team Kill) — убийство своих по фракции.

RK (Revenge Kill) — месть после смерти (запрещено).

MG (Meta Gaming) — использование информации, которой персонаж не знает.

PG (Power Gaming) — действия, невозможные в реальной жизни.

IC (In Character) — от лица персонажа.

OOC (Out Of Character) — от лица игрока.

ГМ (God Mode) — режим бессмертия (чит).

БХ (Bunny Hop) — прыжки для ускорения (чит).

Фаст-Сват — быстрый вход в здание (запрещено).

Спавн — место появления игрока.

Скин — внешний вид персонажа.

Чекпоинт — метка на карте.

Пикап — объект для подбора предметов.

Биндер — программа для быстрого ввода команд.

Фракция — организация (МВД, мэрия, больница, банда).

Бизнес — коммерческий объект (магазин, заправка).

Нон-РП — действие, не соответствующее роли.

АФК (AFK) — отошёл от клавиатуры.

Флуд — спам сообщениями в чат.

Кэмп — убийство с одного места (запрещено).

Тим — команда, группа игроков.

Краш — вылет игры.

Лаг — зависание, тормоза.

Баг — ошибка в игре/моде.

Правила РП +

1. Запрещён DM (убийство без причины).

2. Запрещён DB (убийство из машины).

3. Запрещён SK (убийство на спавне).

4. Запрещён TK (убийство своих).

5. Запрещён RK (месть после смерти).

6. Запрещён MG (использование внеигровой информации).

7. Запрещён PG (невозможные действия).

8. Запрещён Фаст-Сват.

9. Запрещён багоюз.

10. Запрещено неадекватное поведение.

Правила чата +

1. Запрещен спам, флуд и оскорбление родных в любых видах чатов.

2. Запрещён капс (крик).

3. Запрещено оскорбление по национальности.

4. Запрещён флуд смайлами.

5. Запрещена реклама.

6. Запрещены угрозы в реале.

7. Запрещён спам командами.

Наказания +

1. Предупреждение — устное.

2. Мут — 10-60 минут.

3. Кик — с сервера.

4. Бан — 1-30 дней.

5. Перманентный бан — навсегда.
